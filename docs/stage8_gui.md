# Этап 8 — графический интерфейс (часть 1)

## Стек

- **tkinter** (стандартная библиотека Python): без дополнительных pip-зависимостей,
  пригодно для Windows и локальной разработки. Переход на PySide6 / Flet и т.п.
  возможен позже без смены доменного ядра.

## Запуск

Из корня репозитория после `pip install -e .` и активации виртуального окружения
используйте интерпретатор из venv (**`python`**, не `py -3`, иначе может стартовать
глобальный Python без пакета). Секреты для HTTP LLM можно положить в ``.env`` в
каталоге данных приложения или в корне проекта (см. README, раздел 4.1).

```text
python -m lang_learn gui
```

Либо консольная команда: `lang-learn gui`. Без установки пакета: `.\scripts\run_gui.ps1` (Windows).

## Возможности (текущая версия)

- **Параметры сессии:** **идентификатор пользователя** (внешний id для БД, по умолчанию
  `gui-user`; смена учётной записи — другой id и перезапуск приложения), тема, цель,
  уровень (`level_hint`), целевой язык, выбор **траектории** (информативно из этапа 7).
- **Диалог:** лента «Вы» / «Ассистент», ответы через ``DialogOrchestrator`` и
  выбранный в параметрах **провайдер LLM** из ``ProviderRegistry`` (ключи из
  ``list_llm()``; сейчас доступен как минимум ``stub``). Последний выбор
  сохраняется в ``gui_preferences.json`` в каталоге данных приложения. История
  передаётся в ``DialogSessionContext.prior_messages``.
- **Ввод текста:** поле внизу окна, кнопка «Отправить», клавиша **Enter**;
  пустой ввод блокируется предупреждением.
- **Прогресс:** панель со сводкой KPI / компетенций / готовности к поездке
  (``compute_progress_overview``); попытки и профиль сохраняются в **SQLite**
  (``SqliteProgressRepository``): по умолчанию файл ``progress.db`` в каталоге
  данных приложения (Windows: ``%LOCALAPPDATA%\lang_learn\``; иначе
  ``$XDG_DATA_HOME/lang_learn`` или ``~/.local/share/lang_learn``). Схема —
  ``db/schema.sql`` из репозитория. При закрытии окна соединение с БД закрывается.

## Ограничения (на потом)

- Нет записи/воспроизведения аудио в UI (этап 1 остаётся в CLI).
- Путь к файлу БД из интерфейса не настраивается — в бэклоге плана (волна A).
