# Этап 2 — Pre-A0 (часть 1): модели, курс, движок, оценка

## Сделано

- **Схемы** `lang_learn.schemas.pre_a0`: курс, буквы, кластеры, минимальные пары,
  типы упражнений.
- **Данные** `lang_learn/data/pre_a0/en_sample.json` (пример латиницы `en-US`).
- **Загрузка** `lang_learn.learning.course_loader.load_packaged_en_sample()`.
- **Произношение (MVP)** `lang_learn.learning.pronunciation`: нормализация текста,
  `utterance_similarity`, проверка ключевых графем.
- **Движок** `PreA0LessonEngine`: линейная очередь + повтор при ошибке
  (порог `accept_threshold`).
- **CLI** `python -m lang_learn prea0-demo` — один цикл «упражнение + эталонный ответ».
